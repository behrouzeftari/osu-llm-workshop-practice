Lesson 2: Changing Permissions

Now that you can read permissions, here's how to change them. Two tools: chmod (change mode) for permission bits, and chown/chgrp for owner and group.

chmod — symbolic mode

Syntax: chmod [who][+|-|=][permissions] file

WhoMeaning
uUser (owner)
gGroup
oOthers
aAll (u+g+o)

Examples:

chmod u+x script.sh          # Owner gains execute
chmod go-w notes.txt         # Group and others lose write
chmod a=rX README.md         # Everyone gets read; directories get execute
chmod ug+rw,o-rwx secret/    # Owner+group read/write, others nothing

Capital X

X (capital) means "execute only if the file is a directory or already has execute for someone." Use a+rX to recursively make directories traversable without making regular files executable.

chmod — numeric (octal) mode

Each digit = sum of bits: 4=read, 2=write, 1=execute.

DigitBinaryMeaning
7111rwx
6110rw-
5101r-x
4100r--
0000---

Three digits = owner, group, others. A leading fourth digit is for special bits (Lesson 3).

chmod 755 script.sh     # rwxr-xr-x
chmod 640 data.csv      # rw-r-----
chmod 700 private/      # rwx------
# chmod -R 644 public/  # BROKEN: applies 644 to directories too (removes execute)
# Correct recursive pattern:
chmod -R a+rX public/   # Files: add read; dirs: add read+execute
# Or two steps:
# chmod -R 644 public/ && find public/ -type d -exec chmod 755 {} \;

When to use which

Symbolic is great for tweaking one thing (u+x). Numeric is faster when you know the exact final state (scripts, dotfiles, automation). Both are standard; pick what's clearer.

chown and chgrp

chown alex report.pdf           # Change owner to alex
chown alex:students report.pdf  # Change owner and group
chgrp students report.pdf       # Change group only
chown -R alex:staff project/    # Recursive

Only root can change the owner. Any user can change the group of a file they own, but only to a group they belong to.

Umask — default permissions for new files

umask masks off bits when files are created. Typical umask 022 → new files get 644 (rw-r--r--), directories get 755 (rwxr-xr-x).

umask           # Show current (octal)
umask 027       # New files: 640, new dirs: 750
